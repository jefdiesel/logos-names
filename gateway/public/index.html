Logos Names

Names like jef.lez for the Logos Execution Zone. Pay a name instead of a 32-byte account. The chain never sees the name, so nobody can list or browse them.

Install the command line

One binary for macOS (Apple silicon) and Linux (x86_64), with the LEZ wallet built in. It needs nothing else and doesn't need Basecamp.

curl -fsSL https://logos-names.wrapit.workers.dev/install.sh | sh

It installs to ~/.local/bin/names and checks the download's SHA-256.

Look names up

No wallet or setup needed:

names resolve jef.lez        # what the name points to, as JSON
names reverse <account>      # the name an account goes by
names settings               # the registry's prices

Get a name

1. Make a wallet and an account. Write down the recovery phrase it prints.

names wallet account new public

2. Fund the account. LEZ testnet tokens come from the Logos Blockchain through a channel deposit to your account ID, or from anyone who already holds some. The sequencer only accepts a transaction if the payer could cover its maximum fee, so keep about 20,000,000 in the account. Check the balance with:

names wallet account get --account-id Public/<account>

3. Register, then point the name somewhere:

names register myname --owner <account> --term 1y   # 30d, 1y or 5y
names receive-privately myname                     # payments to myname.lez stay private
names set-text myname chat <address>               # optional text entries
names set-page myname index.html                   # optional page at /myname

Pay a name

names pay jef.lez 1000 --from <account>             # to its public account
names pay jef.lez 1000 --from <account> --private   # shielded; the proof takes minutes

Payments sent with --private land on a fresh private account. The recipient finds them with names wallet account sync-private.

More

names --help lists every command: renew, transfer, release, clear-page and more. names wallet help lists the wallet's own commands. The wallet lives in ~/.lee/wallet; set LEE_WALLET_HOME_DIR to use another one.

Apps and agents can read any name as JSON at /<name>/.well-known/logos-name.json on this gateway.

Logos testnet v0.3 is experimental, and names registered on it will need to move when testnet v0.4 arrives. While the testnet's sequencer is stalled, lookups still work but changes wait until it produces blocks again.

Logos Names runs on the Logos Execution Zone testnet. This gateway only reads the chain; it can see which names you look up.
