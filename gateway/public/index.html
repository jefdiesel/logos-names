Logos Names

Names like jef.lez for the Logos Execution Zone. Pay a name instead of a 32-byte account. The chain never sees the name, so nobody can list or browse them.

This runs on the public LEZ testnet (testnet v0.3). Its tokens are test tokens, free from the faucet below and worth nothing. Names won't carry over to testnet v0.4.

Install the command line

One binary for macOS (Apple silicon) and Linux (x86_64), with the LEZ wallet built in. It needs nothing else and doesn't need Basecamp.

curl -fsSL https://logos-names.wrapit.workers.dev/install.sh | sh

It downloads from this project's GitHub releases, installs to ~/.local/bin/names with man pages (man names), and checks each download's SHA-256.

Look names up

No wallet or setup needed:

names resolve jef.lez        # expiry, whether it can be paid, text entries, page
names settings               # the registry's prices

Get a name

1. Make a wallet and an account. Write down the recovery phrase it prints.

names wallet account new public

2. Fund it. Either bridge your own tokens from the Logos Blockchain through your own node (Basecamp's Blockchain app, or a headless node; mine some first with its Fund button), or take 20,000,000 from the faucet, once a day per account. Either covers a registration and many changes.

names bridge 20000000 --to Public/<account> --from-key <your node's key>        # shows the plan
names bridge 20000000 --to Public/<account> --from-key <your node's key> --yes  # deposits
names faucet Public/<account>                                               # or this
names wallet account get --account-id Public/<account>                      # check the balance

A bridge deposit is credited once its Logos Blockchain block is final, which takes hours on today's testnet. --node points it at your node's API if it isn't Basecamp's 127.0.0.1:8080; the key is a public key listed in the node's wallet.

3. Make a private account to hold the name, and move some tokens into it. The chain never sees a private holder: each change to the name is proven on your machine, which takes a few minutes.

names wallet account new private
names wallet auth-transfer send --from Public/<account> --to Private/<private> --amount 1000000

4. Register, then point the name somewhere:

names register myname --owner Private/<private> --term 1y   # 30d, 1y or 5y; payable at once
names set-text myname chat <address>               # optional text entries
names set-page myname index.html                   # optional page at /myname

Pay a name

names pay jef.lez 1000 --from Private/<private>   # nobody sees payer, recipient or amount
names pay jef.lez 1000 --from Public/<account>     # works too, but shows you as the payer

A name never shows an address. It carries private receiving keys, made when it is registered, and every payment goes to them: the chain shows neither the recipient nor the amount, and nobody, the payer included, learns the account behind the name. The recipient finds payments with names wallet account sync-private. Everything private (holding a name, shielding tokens, private payments) is proven on your machine by RISC Zero's prover, r0vm, which the installer fetches from RISC Zero's own release.

For AI agents

An MCP server lets Claude, or any MCP client, look names up as tools: resolve_name and get_page. It is one file, needs Node 20 or later, reads the public LEZ testnet by default and never signs or sends anything.

curl -fsSLo ~/.logos-names-mcp.js https://logos-names.wrapit.workers.dev/mcp.js
claude mcp add --scope user logos-names -- node ~/.logos-names-mcp.js

For other clients, run node ~/.logos-names-mcp.js over stdio: {"command": "node", "args": ["/full/path/to/.logos-names-mcp.js"]}. node ~/.logos-names-mcp.js --help explains the rest, and mcp.js.sha256 checks the download. A name's page is written by its owner, so the server hands it over as untrustedContent: data for the agent, never instructions.

More

names --help or man names lists every command: renew, transfer, release, clear-page and more. names wallet help lists the wallet's own commands. The wallet lives in ~/.lee/wallet; set LEE_WALLET_HOME_DIR to use another one.

Apps and agents can read any name as JSON at /<name>/.well-known/logos-name.json on this gateway. names and the MCP server don't need it: they talk to the LEZ sequencer directly (https://testnet.lez.logos.co) and read the registry's program from the chain itself, so no server of ours sits between you and the chain. Pass --rpc and --program to use another chain or registry.
