Logos Names

Names like jef.lez for the Logos Execution Zone. Pay a name instead of a 32-byte account. The chain never sees the name, so nobody can list or browse them.

This runs on the Logos Names test chain, a LEZ chain kept running for this registry while the public LEZ testnet is halted, and anchored to the Logos Blockchain: every block is posted there. Its tokens come free from the faucet below and are worth nothing. Names here won't carry over to the public testnet or to testnet v0.4.

Install the command line

One binary for macOS (Apple silicon) and Linux (x86_64), with the LEZ wallet built in. It needs nothing else and doesn't need Basecamp.

curl -fsSL https://logos-names.wrapit.workers.dev/install.sh | sh

It installs to ~/.local/bin/names, with man pages (man names), and checks each download's SHA-256.

Look names up

No wallet or setup needed:

names resolve jef.lez        # what the name points to, as JSON
names reverse <account>      # the name an account goes by
names settings               # the registry's prices

Get a name

1. Make a wallet and an account. Write down the recovery phrase it prints.

names wallet account new public

2. Fund it from the faucet: 50,000,000 test tokens, once a day per account. That covers many registrations and changes.

names faucet Public/<account>
names wallet account get --account-id Public/<account>   # check the balance

3. Make a private account to hold the name, and move some tokens into it. The chain never sees a private holder: each change to the name is proven on your machine, which takes a few minutes.

names wallet account new private
names wallet auth-transfer send --from Public/<account> --to Private/<private> --amount 1000000

4. Register, then point the name somewhere:

names register myname --owner Private/<private> --term 1y   # 30d, 1y or 5y
names receive-privately myname                     # payments to myname.lez stay private
names set-text myname chat <address>               # optional text entries
names set-page myname index.html                   # optional page at /myname

Pay a name

names pay jef.lez 1000 --from <account>             # to its public account
names pay jef.lez 1000 --from <account> --private   # shielded; the proof takes minutes

Payments sent with --private land on a fresh private account. The recipient finds them with names wallet account sync-private. Sending one needs RISC Zero's prover (r0vm, 3.0.5), which comes with curl -L https://risczero.com/install | bash && rzup install cargo-risczero 3.0.5; nothing else does.

For AI agents

An MCP server lets Claude, or any MCP client, look names up as tools: resolve_name, get_page and reverse_lookup. It is one file, needs Node 20 or later, reads this chain by default and never signs or sends anything.

curl -fsSLo ~/.logos-names-mcp.js https://logos-names.wrapit.workers.dev/mcp.js
claude mcp add --scope user logos-names -- node ~/.logos-names-mcp.js

For other clients, run node ~/.logos-names-mcp.js over stdio: {"command": "node", "args": ["/full/path/to/.logos-names-mcp.js"]}. node ~/.logos-names-mcp.js --help explains the rest, and mcp.js.sha256 checks the download. A name's page is written by its owner, so the server hands it over as untrustedContent: data for the agent, never instructions.

More

names --help or man names lists every command: renew, transfer, release, clear-page and more. names wallet help lists the wallet's own commands. The wallet lives in ~/.lee/wallet; set LEE_WALLET_HOME_DIR to use another one.

Apps and agents can read any name as JSON at /<name>/.well-known/logos-name.json on this gateway. The chain's JSON-RPC is at /rpc, and any LEZ v0.3.1 wallet can use it: names does by default; to use a different chain, pass --rpc and --program.

Logos Names runs on its own LEZ test chain. This gateway can see which names you look up, and it passes on the transactions you send.
