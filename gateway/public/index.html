Logos Names

Names like jef.lez for the Logos Execution Zone. Pay a name instead of a 32-byte account. The chain never sees the name, so nobody can list or browse them.

This runs on the public LEZ testnet (testnet v0.3). Its tokens are test tokens and worth nothing. Names won't carry over to testnet v0.4.

Install the command line

One binary for macOS (Apple silicon) and Linux (x86_64), with the LEZ wallet built in. It needs nothing else and doesn't need Basecamp.

curl -fsSL https://logos-names.wrapit.workers.dev/install.sh | sh

It downloads from this project's GitHub releases, installs to ~/.local/bin/names with man pages (man names), and checks each download's signature and SHA-256.

Look names up

No wallet or setup needed:

names resolve jef.lez        # expiry, whether it can be paid, text entries, page
names open jef.lez           # show its page in your browser, served from your own machine
names settings               # the registry's prices

Get a name

names setup                # wallet and accounts; run again once funded, for a private balance
names register myname      # held privately; payable at once
names mine                 # the names you hold
names balance              # what you have, public and private

setup prints a recovery phrase: write it down. It makes a public and a private account. Send the public one some testnet tokens from your LEZ wallet (or with names bridge from the Logos Blockchain) and run setup again: it moves some to the private account, which then holds your names and pays from. Private actions are proven on your machine and take a few minutes each. register returns once the name is committed and finishes by itself about 20 minutes later; names mine shows when.

Optional extras:

names set-text myname chat <address>      # text entries
names set-page myname index.html          # a page
names set-account myname <account>        # also payable publicly, at a visible account
names set-logos-account myname <address>  # link a Logos account (AccountLog)

Pay a name

names pay jef.lez 1000              # from your private account: nobody sees payer, recipient or amount
names pay shop.lez 1000 --public    # to a public account the holder published

Names are private by default. Each carries private receiving keys, made when it is registered, and payments go to them: the chain shows neither the recipient nor the amount, and nobody, the payer included, learns the account behind the name. A holder can also publish a public account with names set-account myname <account>, for names meant to be paid openly; anyone who resolves the name then sees that account. The recipient finds payments with names wallet account sync-private. Everything private (holding a name, shielding tokens, private payments) is proven on your machine by RISC Zero's prover, r0vm, which the installer fetches from RISC Zero's own release.

For AI agents

An MCP server lets Claude, or any MCP client, look names up as tools: resolve_name and get_page. It is one file, needs Node 20 or later, reads the public LEZ testnet by default and never signs or sends anything.

curl -fsSLo ~/.logos-names-mcp.js https://logos-names.wrapit.workers.dev/mcp.js
claude mcp add --scope user logos-names -- node ~/.logos-names-mcp.js

For other clients, run node ~/.logos-names-mcp.js over stdio: {"command": "node", "args": ["/full/path/to/.logos-names-mcp.js"]}. node ~/.logos-names-mcp.js --help explains the rest, and mcp.js.sha256 checks the download. A name's page is written by its owner, so the server hands it over as untrustedContent: data for the agent, never instructions.

More

names --help or man names lists every command: renew, transfer, release, clear-page and more. names wallet help lists the wallet's own commands. The wallet lives in ~/.lee/wallet; set LEE_WALLET_HOME_DIR to use another one.

To see a name's page, run names open jef.lez: the page is read from the chain on your machine and shown in your browser from 127.0.0.1, so no server learns which name you opened, and the page can't load anything from the internet. This website never looks names up. names and the MCP server talk to the LEZ sequencer directly (https://testnet.lez.logos.co) and read the registry's program from the chain itself, so no server of ours sits between you and the chain. Pass --rpc and --program to use another chain or registry.
